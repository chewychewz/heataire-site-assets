# heataire-site-assets

Archive and hosted assets for the Swiss grey heat pump pages (pool and hot water). Shelved as the launch look, kept for a future site on another domain.

Start with `docs/DESIGN-NOTES.md`. To see the design, open `prototype/swiss-both-pages.html` in a browser.

Hosted by Webflow draft pages via jsDelivr, pinned to commits. Do not delete this repo while those pages exist.
